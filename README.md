# GigFlow Smart Leads Dashboard

## Features

- User Authentication
- JWT Authorization
- Create Leads
- Get Leads
- Update Leads
- Delete Leads
- MongoDB Database
- React Frontend
- Express Backend

## Tech Stack

Frontend:
- React
- Vite
- Axios

Backend:
- Node.js
- Express
- MongoDB
- TypeScript

## Backend Setup

cd server
npm install
npm run dev

## Frontend Setup

cd client
npm install
npm run dev
