# GigFlow CRM Dashboard

A modern full-stack CRM dashboard built using React, TypeScript, Node.js, Express, MongoDB, and Tailwind CSS.

This project helps teams manage leads, track activities, monitor conversions, and visualize CRM analytics in a clean SaaS-style interface.
